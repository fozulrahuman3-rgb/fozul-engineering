# concrete-deterioration

Destination folder for real photography from **Project Group B — Concrete
Spalling and Exposed Reinforcement Assessment**.

No image files exist here yet. Planned filenames and per-image metadata
(alt text, caption, category, image type, confidentiality note, featured
flag) are tracked in `src/data/projectImagery/concrete-deterioration.js`.

Before adding real files, see `IMAGE_UPLOAD_CHECKLIST.md` at the project
root for destination/filename/caption/alt-text conventions and the
face-blur / logo-and-badge review step.
