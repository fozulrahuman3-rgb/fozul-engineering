Destination folder for real photography from **Project Group A — Industrial
Rotary Kiln / Process Plant Inspection**.

(alt text, caption, category, image type, confidentiality note, featured

root for destination/filename/caption/alt-text conventions and the
face-blur / logo-and-badge review step.
